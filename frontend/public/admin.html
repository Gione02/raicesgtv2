¿Cómo publico los cambios?
  1. Agrega, edita o elimina productos aquí. Los cambios se guardan como borrador en este navegador.
  2. Pulsa “Descargar producto.js”.
  3. Reemplaza el archivo frontend/public/js/producto.js del proyecto con el descargado.
  4. Copia las fotos nuevas a frontend/public/img/ con el nombre exacto que indica cada producto.
  5. Sube los cambios a GitHub y reconstruye: docker compose up -d --build.

Los cambios no se publican solos: el sitio todavía no está conectado a la base de datos. Cuando se conecte al API, este panel podrá guardar directamente.
